Win顺 0.42.1（自用构建）合并上游 0.42.0：新增剪贴板同步插件，在几台 Windows 电脑和 Mac（Mac顺）之间端到端加密地同步文字、图片和文件，不用账号也没有服务器；剪贴板里的图片可以点开看大图，图中的文字默认收起；选中文字后按快捷键即可翻译（鼠标手势 2.1.0）；OneCommander 里也能直接打字搜索；截图可以跨屏框选；「粘贴为纯文本」快捷键在任何程序里都能用；搜索框阴影可以调浅或关掉。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.42.1 (a personal build) merges upstream 0.42.0: a new clipboard sync plugin copies text, pictures and files between your Windows PCs and Macs running Mac顺, end to end encrypted, with no account and no server; pictures in the clipboard open large and their words fold; a shortcut for selected text translates it (mouse gestures 2.1.0); typing searches right in OneCommander; screenshots span several monitors; a paste-as-plain-text key works in any program; and the search box shadow can be lighter or off. The personal 运行 tray icons, switch and scope memory stay.

## 新功能 · What's new

- 🔁 **同步上游 0.42.0** 剪贴板同步（新插件）：Windows 与 Mac顺之间同步剪贴板，X25519 + AES-256-GCM 端到端加密，配对用 6 位数字，文件按需接收（ShunSync v1 协议）；剪贴板大图与图中文字折叠（#414）；选中文字后的快捷键，默认翻译，浏览器里也能用（鼠标手势 2.1.0）；文件夹菜单的完整路径提示跟随「悬停提示」开关（#413）；「粘贴为纯文本」全局快捷键，如 PureText（#408）；跨屏截图（截图与录屏 1.1.30，#409）；OneCommander 里直接打字搜索；搜索框阴影标准/浅/无（#412）；插件关键字后按 `Shift+Tab` 按名字搜（#411）；正则搜索先按确定字面量筛再跑表达式，快了很多（#411）；空文件夹/空文件标记挪到名字后面（#391）；Everything 结果上限改为 512 MB（#399）；Windows 10 1809（LTSC 2019）可录屏；浏览器里滚轮从第二格起切标签页；「留着，不清」改为 Ctrl+Enter；截图与录屏 1.1.30、鼠标手势 2.1.0、图片文字搜索 1.0.27、开发工具 1.0.2 等插件更新。

  **Upstream 0.42.0 merged** Clipboard sync (new plugin): the clipboard between Windows PCs and Macs running Mac顺, end to end encrypted with X25519 + AES-256-GCM, paired by six digits, files received on demand (the ShunSync v1 protocol); pictures large in the clipboard with their words folded (#414); a shortcut for selected text, translating by default, browsers included (mouse gestures 2.1.0); the folder menu's full path tip follows the hover tips switch (#413); a paste-as-plain-text key, as PureText (#408); screenshots over several monitors (screenshot and recording 1.1.30, #409); typing searches right in OneCommander; the search box shadow standard / light / none (#412); Shift+Tab after a plugin keyword searches names (#411); regex search narrows by the sure literal first, much faster (#411); the empty folder / empty file tag sits after the name (#391); Everything answers are capped by 512 MB instead of 200 000 rows (#399); recording on Windows 10 1809 (LTSC 2019); the wheel switches browser tabs from the second notch; 留着，不清 is Ctrl+Enter; screenshot and recording 1.1.30, mouse gestures 2.1.0, image text search 1.0.27 and developer tools 1.0.2 come with it.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
