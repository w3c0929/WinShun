Win顺 0.36.1（自用构建）合并上游 0.36.0：新装默认像 Listary（对话框旁搜索框、双击空白处的文件夹菜单、资源管理器里直接打字默认开启）；设置 › 外观 › 悬停提示 可以关掉鼠标停出来的说明；WPS 里的公式从剪贴板粘回去还能编辑；WebP、HEIC 图片在剪贴板列表里有缩略图；在文件夹里打字可以带文件类型；软件内更新从这一版起只下载变了的部分。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.36.1 (a personal build) merges upstream 0.36.0: Listary-style from the start (the bar by dialogs, the folder menu and typing in Explorer are on for new installs); hover tips can be turned off under Settings › Appearance; WPS formulas paste back editable; WebP and HEIC files show thumbnails in the clipboard list; typing in a folder can name a kind of file; and in-app updates from this version download only what changed. The personal 运行 tray icons, switch and scope memory stay.
