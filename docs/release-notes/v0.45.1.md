## 新功能 · What's new

- 🎥 **录屏与截图** 录屏“超清”画质与 60 帧，文字和彩色细节更清楚，可加鼠标拖尾；贴图分组、截图后直接贴到屏幕、关掉的贴图可找回、`Ctrl+S` 存回原文件；截图聚光灯；长截图自动连续滚动（截图与录屏插件更新）。

  **Recording and capture** Ultra quality and 60 frames in recordings, with a cursor trail; pins group, a screenshot pins straight to the screen, closed pins come back, Ctrl+S writes an edited picture back; a capture spotlight; long screenshots scroll on by themselves.

- 🔎 **搜索与操作** FZF 模糊匹配（#422）；搜索框里直接关机、重启、锁屏（#428）；快捷菜单的“移到回收站”（#434）；`Ctrl++` / `Ctrl+-` / `Ctrl+0` 调整界面大小；DialogBar 可选用空输入的候选来源（#438）；文件夹窗口的搜索框 Tab 补全并可进入文件夹（#454）。

  **Search and actions** FZF fuzzy terms (#422); shut down, restart and lock the PC from the box (#428); Move to Recycle Bin in the quick menu (#434); Ctrl++/Ctrl+-/Ctrl+0 size the interface; the dialog bar chooses its empty-query suggestions (#438); Tab completes and steps into folders in a folder window's search box (#454).

- ⚙️ **界面与插件** 插件库的设置与管理移到插件卡片上；首次运行向导（截图与剪贴板历史初始开启）；悬停提示分类（界面/行操作/文件夹菜单路径，#440）；Tessoa 的打开/保存窗口兼容；Aero Basic 边框渗出修复与搜索面板布局完善。

  **Interface and plugins** Plugin library settings and management on the tiles; a first-run guide (clipboard history and the screenshot on at first); hover tips categorized (#440); Tessoa's Open/Save window works; the Aero Basic frame bleed on layered windows is fixed and the search panel's layout refined.

- 🧩 **自用保留** 悬停行显示选中样式（白底+边框+竖条）、方向键与鼠标互斥（上游 0.45.0 未包含此功能，本版继续采用自建实现）；运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The hovered row wearing the current row's face (white face, border, bar) and the keys and the pointer taking turns (not in upstream 0.45.0: the personal implementation stays); the tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
