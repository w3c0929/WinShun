## 新功能 · What's new

- 📋 **剪贴板** 常用的一条可以设快捷键，在任何程序里一按就粘贴它；保留重复复制的内容（Ditto 的两种习惯都能照旧）；全屏游戏里打开的剪贴板面板不再一闪就没（#452）。

  **Clipboard** A favorite entry gets a shortcut that pastes it in any program; duplicates stay as copied (Ditto habits kept); the panel stays up over a full-screen game (#452).

- 🗜️ **压缩包搜索（新插件）** 按文件名在 zip、7z、rar 等压缩包里找文件，不用解压；`list_files` 可按类型成页列出名字索引里的文件。

  **Archive search (new plugin)** Files inside zip, 7z, rar and the like are found by name without unpacking; `list_files` lists files of some types from the name index, a page at a time.

- 🎨 **界面与操作** 面板可按名称筛选（首尾、排除词，#457）；搜索框 Logo 可以关掉（#433）；插件库可“不感兴趣”（#442）；“始终置顶”插件给窗口加一圈线（1.1.0）；截图快捷键（#455）、钉图的标签页可沿上边缘拖动（#456）。

  **Interface and actions** The panel filters by name (#457); the box's Logo can be switched off (#433); 不感兴趣 in the plugin library (#442); the Always on top plugin draws a line round its windows (1.1.0); capture keys (#455); a pin's tab drags along its top edge (#456).

- 🖱️ **悬停样式（按上游）** 上游在 #429 中决定：列表始终只有一行“选中”，鼠标悬停只做浅提示，不抢选中；白底盖住行内容的问题上游 0.45.0 已修复。本版采用上游行为，自建的悬停样式与键盘/鼠标互斥不再保留。

  **The hovered row (upstream's call)** Upstream decided in #429 that only one row is ever 选中 and the pointer gets a faint hint without taking it; the white face hiding a row was fixed upstream in 0.45.0. This build follows upstream; the personal hover face and key/pointer turns are gone.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
