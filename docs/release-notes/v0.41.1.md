Win顺 0.41.1（自用构建）合并上游 0.41.0：收藏夹圆盘分成每页 8 个，按 Tab 翻页，能放下更多文件夹收藏；鼠标手势插件 2.0 支持规则、圆圈、角落、边缘和滚轮，带卡片和设置窗口；剪贴板记住上次打开的标签；新增文字扩展插件。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.41.1 (a personal build) merges upstream 0.41.0: the favorites drop pie has pages of eight, turned with Tab, so more folders fit; mouse gestures 2.0 adds rules, circles, corners, edges and the wheel, with cards and a settings window; the clipboard opens on the tab it was left on; and a text expander plugin is new. The personal 运行 tray icons, switch and scope memory stay.

## 新功能 · What's new

- ⬆️ **同步上游 0.41.0** 收藏夹圆盘每页 8 个，Tab 翻页，中心显示页数（#405）；鼠标手势 2.0：手势、圆圈、角落、边缘和滚轮统一成一种规则，带卡片和独立设置窗口，可选词读取与系统电源权限；剪贴板记住上次打开的标签（#404）；新增文字扩展插件（#403）；捐赠对话框改进；长截图不再留下空帧；LocalSend、休息提醒、翻译、图片文字搜索、开发工具用 0.41.0 的共享代码重编译。详见上游 0.41.0 的发布说明。

  **Upstream 0.41.0 merged** The favorites drop pie has pages of eight turned with Tab, the centre showing the page (#405); mouse gestures 2.0 unifies gestures, circles, corners, edges and the wheel into one kind of rule, with cards and a settings window of its own, selected-word reading and a system power permission; the clipboard opens on the tab it was left on (#404); a text expander plugin is new (#403); the donate dialog is reworked; long screenshots leave no empty frame; LocalSend, Break, Translate, image text search and developer tools are rebuilt with 0.41.0's shared code. See the upstream 0.41.0 notes.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
