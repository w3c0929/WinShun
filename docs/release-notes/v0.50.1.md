## 新功能 · What's new

- 🧮 **公式识别** 截图里框住公式按 `Shift+F`，读成 LaTeX，可复制为 Word 公式、Markdown 或 Typst；模型在本机运行（首次按需下载），截图、贴图与编辑器里都能用。

  **Formula recognition** Frame a formula in a capture and press Shift+F to read it as LaTeX, copied as a Word equation, Markdown or Typst; the model runs on this PC (fetched on demand), in captures, pins and the editor.

- 🎨 **选中的行更醒目的四种外观**（#474）brand 深色选中行为白色 10% 并带一圈更亮的边，liquid、fluent、tactile 的选中/图块/卡片与悬停拉开距离；浅色下副文字与弱文字加深，在选中行上也看得清。

  **Selection that stands clear in all four themes** (#474) Brand dark's selected row is white 10 % with a lighter rim; liquid, fluent and tactile keep selection, tiles and cards clear of hover; light-theme secondary and faint text is darker and readable on a selected row.

- ⚡ **内存紧张时不再卡顿**（#471）Windows 内存不足时，空闲保留的内存让出来，呼出搜索框和第一次搜索不再卡上几秒。

  **No stall when memory is short** (#471) While Windows is short of memory, the idle reservation steps aside, so the first open and search no longer stall for seconds.

- 🖱️ **手势带修饰键**（#472）按住 `Ctrl`、`Alt`、`Shift` 画出的手势是一套独立的规则；带和弦的手势按钮会等第二个键（#436）。

  **Gestures with a modifier** (#472) With Ctrl, Alt or Shift held, a gesture is a rule of its own; a gesture button with a chord waits for the second key (#436).

- 🔧 **其他** 文件类型扩展名填 `*` 只分文件和文件夹；关机、重启等命令归到“系统开关”插件（#477）；文件夹窗口的搜索框输入路径会列出其指向位置（#454）；`Shift+Tab` 在单独的关键字上按也按名字搜（#479）；剪贴板大图替换更顺（#414）；Photoshop 能读到在其上复制的图片（#432）；索引链接文件夹显示链接指向的内容（#460）；空闲时插件归还内存（#478）。

  **The rest** A file type's * means every file; shut down and restart move to the System switches plugin (#477); a path typed in a folder window's box lists where it leads (#454); Shift+Tab on a lone keyword searches names (#479); the clipboard's large picture swaps in one go (#414); Photoshop reads a copy made over it (#432); index link folders show what the links lead to (#460); plugins give memory back while idle (#478).

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
