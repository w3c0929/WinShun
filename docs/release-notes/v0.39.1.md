Win顺 0.39.1（自用构建）合并上游 0.39.0：设置里的收藏夹可以按列排序，也能恢复到排序前的顺序；插件页改成卡片网格，已安装、插件库、内置功能分开；设置标题栏新增“捐赠”按钮；长细图片不再占用大量内存或导致程序结束；崩溃记录会写明程序停在哪里；搜索历史也记录插件关键字搜索。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.39.1 (a personal build) merges upstream 0.39.0: favorites in Settings sort by a column and return to their earlier order; the Plugins page is a grid of tiles for installed, library and built-in plugins; the Settings title bar has a Donate button; long thin pictures no longer take gigabytes or end the program; crash records say where the program stopped; search history keeps plugin keyword searches too. The personal 运行 tray icons, switch and scope memory stay.

## 新功能 · What's new

- ⬆️ **同步上游 0.39.0** 设置 › 收藏夹可按列排序，再点一次（没有箭头）恢复排序前的顺序，另有“恢复默认”按钮；设置 › 插件 改成网格卡片，已安装、插件库、内置功能分开，插件可单独打开，点“设置”时插件没运行会先启动；设置标题栏新增“捐赠”按钮；长细图片不再占用数 GB 内存或导致程序结束，崩溃日志写明停在哪里；搜索历史也记录插件关键字搜索（#395）。详见上游 0.39.0 的发布说明。

  **Upstream 0.39.0 merged** Settings › Favorites sorts by a column and a third click (no arrow) brings back the earlier order, with a Restore defaults button; Settings › Plugins is a grid of tiles for installed, library and built-in plugins, each opened on its own, and a plugin that is not running is started for its Settings; the Settings title bar has a Donate button; long thin pictures no longer take gigabytes or end the program, and crash logs say where it stopped; search history keeps plugin keyword searches too (#395). See the upstream 0.39.0 notes.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
