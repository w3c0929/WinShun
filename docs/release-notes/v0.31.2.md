Win顺 0.31.2（自用构建）合并上游 0.31.0 与 0.31.1：文件夹菜单可以走进子文件夹，计算器会记下算过的账，其他软件可以把 Win顺 当作 Everything 搜索；界面字体可以按文件加载，搜索内存约降两成；自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.31.2 (a personal build) merges upstream 0.31.0 and 0.31.1: the folder menu walks into subfolders, the calculator keeps a tape, other programs can search WinShun as Everything, the interface font is loaded from its file, and searching uses about a fifth less memory; the personal 运行 tray icons, switch and scope memory stay.

## 新功能 · What's new

- ⬆️ **同步上游 0.31.0 / 0.31.1** 文件夹菜单的文件夹行多了箭头，可以一层层进入子文件夹；计算记录用 `=` 列出，可复制、改回、删除；设置 › 打开 Win顺 › 对话框 可让 Directory Opus、Total Commander、`es.exe` 把 Win顺 当作 Everything 搜索（默认关）；界面字体列表可以直接搜索，“霞鹜文楷”常规体和单独列出的字重都能用；搜索时内存约降两成；剪贴板窗口的按键和卡顿、截图卡顿都会写入诊断日志；资源管理器标签页 1.1.2 修复 `Win+E` 出两个窗口的问题。详见上游 0.31.0、0.31.1 的发布说明。

  **Upstream 0.31.0 / 0.31.1 merged** A folder's row in the folder menu has an arrow into its subfolders; the calculator's `=` lists the sums taken, to copy, reuse or remove; Settings › Open WinShun › Dialogs lets Directory Opus, Total Commander and `es.exe` search WinShun as Everything (off by default); the interface font list has a search row, and LXGW WenKai regular and separately listed weights work; searching uses about a fifth less memory; the clipboard's keys and stalls and the capture's stalls are written to the diagnostics; Explorer tabs 1.1.2 fixes two windows from a double `Win+E`. See the upstream 0.31.0 and 0.31.1 notes.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.

- 🔌 **插件** 截图与录屏 1.1.17、图片文字搜索 1.0.16（从插件库更新）。截图卡住时更新插件后，诊断日志能记下当时在做什么。

  **Plugins** Screenshot and recording 1.1.17, image text search 1.0.16, from the plugin library. With the updated capture plugin, a stall is written to the diagnostics.
