The personal 运行 tray icons, switch, scope and double-click memory stay.

## 新功能 · What's new

- 📌 **固定的搜索框常驻任务栏**（上游 #418）中键（或 `Ctrl+T`）固定后，搜索框成为普通窗口：任务栏出现按钮，`Alt+Tab` 可切换，任务栏按钮和 `Win+D` 可以最小化，再次按下或热键回到原处；在最小化时从任务栏关闭，会先恢复再隐藏，下次打开一如往常。取消固定后恢复为不占任务栏的悬浮搜索框。此项采用上游实现，替换自建版的临时方案。

  **The pinned box on the taskbar** (upstream #418) Pinned (the middle button or `Ctrl+T`), the search box is a window of its own: a taskbar button, `Alt+Tab`, minimized by that button and Win+D and back where it stood, and closed from the taskbar while minimized it is restored before hiding, so the next opening is as always. Unpinned, it is the floating box it was. This is upstream's implementation, replacing the personal build's.

- 📂 **文件夹菜单改进** 收藏的应用可以折成一组，随手展开折叠；全内联模式把收藏、最近和已打开的文件夹直接列在第一层；收藏类型筛选；Directory Opus 的“此电脑”中也支持，且支持中键；分组分隔线。

  **Folder menu** The favorite apps fold into a group, opened and closed in place; an all-inline mode lists favorites, recent and open folders at the first level; a favorite type filter; works in Directory Opus's This PC and with the middle button; group separators.

- ✂️ **贴图与截图** 贴图后自动 OCR 的文字层可以直接拖选、`Shift+C` 复制全部；截图编辑时按 `Esc` 先退出当前标注工具（#415）；文字框编辑中可直接拖动；OCR 气泡排版与其他窗口一致。

  **Pinned pictures and capture** The OCR text layer of a pinned picture can be selected directly, `Shift+C` copies it all; Esc leaves the active annotation tool first (#415); text boxes drag directly while editing; OCR bubbles match the other windows.

- ⚙️ **设置与交互** 结果里右键可默认弹出系统菜单（#420）；索引和排除的文件夹支持 `%VAR%` 环境变量（#421）；对话框旁的搜索框可以设成点进去不列常用位置（#417）；搜索框和剪贴板先淡出再打开设置/关闭（#419 插件窗口恢复原生 DWM 边框与阴影）；服务安装失败时回退受保护文件夹并清理诊断（#424）。

  **Settings and interaction** The system context menu can be the default on a right click (#420); indexed and excluded folders take %VAR% (#421); the dialog bar's click can be set not to list common places (#417); the search box and clipboard fade out before Settings or closing (#419 restores native DWM borders on plugin windows); the service install falls back for protected folders and clears diagnostics (#424).

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
