Win顺 0.26.1（自用构建）改用 Qt 6.12 构建，修复设置窗口打不开的问题；「程序」标签现在在“合并文件与内容”模式下也会显示。 WinShun 0.26.1 (a personal build) is built with Qt 6.12, which fixes the settings window not opening; the 程序 tab now shows in the merged file-and-content mode too.

## 新功能 · What's new

- 🧩 **程序标签（合并模式也显示）** 顶部「程序」用图标网格列出应用：最近使用(N) / 常用软件(N) / 所有程序(N)，可拖拽排序并记住，默认第一项；方向键选择、Enter 打开、输入按名字过滤。

  **The 程序 tab, also in merged mode** A grid of app icons: recently used, starred as often used, or every installed app, with counts; drag their order and it is kept. Arrows pick, Enter opens, typing narrows by name.

- ⭐ **星标常用软件** 悬停图标时右上角出现星标，点击加入/移出「常用软件」（应用收藏）。

  **Star to keep an app** Hover a tile for a star at its top-right; keep it in 常用软件 (app favorites) or remove it.

- 🖱️ **与文件相同的右键菜单** 打开、以管理员身份运行、打开所在位置、复制、复制完整路径、复制名称、加入收藏夹。

  **The same context menu as files.**

- 🛠️ **修复设置打不开** 0.26.0 用 Qt 6.10 构建，上游 0.25 的界面用到 Qt 6.12 才有的属性（如 `Accessible.expanded`），导致设置窗口加载失败。0.26.1 用 Qt 6.12 重新构建。

  **Settings fixed** 0.26.0 was built with Qt 6.10 while upstream 0.25's UI uses Qt 6.12-only properties, so the settings window failed to load. 0.26.1 is built with Qt 6.12.
