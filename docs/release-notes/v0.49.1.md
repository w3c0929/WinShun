## 新功能 · What's new

- 🧠 **本地模型插件** 在自己电脑上跑 AI 模型（GGUF，llama.cpp，OpenAI 兼容接口）；翻译插件的“本地模型”服务与“按意思找”的本地模型可用，完全离线。

  **A local model plugin** Runs an AI model on your own PC (GGUF via llama.cpp, an OpenAI-compatible endpoint); the translation plugin's local model and semantic search's local model use it, fully offline.

- 📊 **复制为表格认得合并单元格** 有线表格按线读取行列与合并单元格，粘进 Excel 就是表格。

  **Copy as table knows merged cells** Ruled tables are read from their lines; pasting into Excel gives a table.

- 📌 **钉住的搜索框** 让位给刚打开的文件，可设成一直钉住；打开过的结果标“已打开”；可以连续逐个打开结果，列表保持原样。

  **The pinned search box** Stands back for a file just opened and can be kept pinned; rows opened are tagged 已打开; results can be opened one after another with the list as left.

- 🎛️ **结果行按钮自选** 行尾显示哪些按钮、什么顺序，都可以在设置里选（含“复制路径”的图标）。

  **A row's buttons, chosen** Which buttons a row shows and in which order is chosen in Settings.

- ⚡ **性能与其他** 读网络共享不拖慢文件管理器（多人时两两并行、无人时加快）；复制整屏截图少占约 200 MB 内存、文字只读一次（#467）；排除目录支持映射盘与整共享；插件命令可设独立快捷键（#466）；多文件夹选中文件合用一个系统菜单（#464）；剪贴板保留重复项。

  **Performance and the rest** Reading network shares no longer slows Explorer; a full-screen screenshot copy uses about 200 MB less memory and reads its words once (#467); excluded folders take a mapped drive or a whole share; a plugin command has a hotkey of its own (#466); files picked in several folders get one menu (#464); the clipboard keeps duplicates.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
