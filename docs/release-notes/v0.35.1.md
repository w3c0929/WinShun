Win顺 0.35.1（自用构建）合并上游 0.35.0：插件库新增鼠标手势，按住右键画一下就能后退、关窗口、叫出搜索框；收藏可以排成图标，预览里直接播放视频，排序多了“打开最多”，长截图也能横着截；软件内更新从下一版起只下载变了的部分。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.35.1 (a personal build) merges upstream 0.35.0: Mouse gestures in the plugin library, favorites as icons, videos playing in the preview, the Opened most sort, sideways long screenshots, and delta updates from the next version on. The personal 运行 tray icons, switch and scope memory stay.

## 新功能 · What's new

- ⬆️ **同步上游 0.35.0** 鼠标手势插件（按住右键画：后退、前进、到顶、到底、关窗口、最小化、叫出搜索框，可自定义）；收藏样式可选图标网格；预览直接播放 MP4/MKV/AVI 等视频；排序新增“打开最多”；长截图支持横向；增量更新（从下一次更新起生效）；网页搜索可指定浏览器；新增“单击预览”；重新打开可回到上次位置（默认关）；钉住的搜索框可设置不置顶；面板新增铺满屏幕按钮；文件夹菜单和直接打字支持 Clover、360 文件夹标签页；书签 2.2.0 支持 Firefox。详见上游 0.35.0 的发布说明。

  **Upstream 0.35.0 merged** Mouse gestures (hold the right button and draw: back, forward, top, bottom, close, minimize, open the search box, each configurable); favorites as an icon grid; MP4/MKV/AVI and more play in the preview; the Opened most sort; sideways long screenshots; delta updates, from the next update on; a chosen browser for web searches; Click to preview; reopen where left off (off by default); a pinned box that need not stay on top; Fill screen in the panel; the folder menu and typing in Clover and 360 Folder tabs; bookmarks 2.2.0 with Firefox. See the upstream 0.35.0 notes.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.

- 🔌 **插件** 鼠标手势、截图与录屏 1.1.23、书签 2.2.0 等（从插件库更新）。

  **Plugins** Mouse gestures, Screenshot and recording 1.1.23, Bookmarks 2.2.0 and others, from the plugin library.
