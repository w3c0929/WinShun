Win顺 0.26.0（自用构建）在搜索框上方新增「程序」标签：用大图标网格列出最近使用、标星常用和全部已安装的应用，右键弹出与文件相同的菜单。此版本基于上游 Win顺 0.25.0。 WinShun 0.26.0 (a personal build) adds a 程序 tab: a large-icon grid of the apps used most, those starred as often used, and every installed app, with the same right-click menu as files. Based on upstream WinShun 0.25.0.

## 下载 · Downloads

- **WinShun-0.26.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板。
- **WinShun-0.26.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **SHA256SUMS.txt** 提供上述文件的 SHA256。

本自用构建暂未附带离线 OCR 安装包与 OCR 组件 ZIP，增强文字识别可在应用内按需下载。This personal build does not include the offline installer or the OCR component ZIP; enhanced text recognition downloads on demand inside the app.

## 新功能 · What's new

- 🧩 **程序标签** 顶部新增「程序」，用图标网格列出应用：最近使用(N) / 常用软件(N) / 所有程序(N)，三项可拖拽调整顺序并记住，默认显示第一项。方向键选择、Enter 打开、输入文字按名字过滤，滚轮滚动；布局、高度和滚动条与文件一致。

  **A 程序 tab** A grid of app icons before 全部: recently used, starred as often used, or every installed app, each with its count. Drag the three choices into their order and it is kept; the first one opens. Arrows pick a tile, Enter opens it, typing narrows by name, the wheel scrolls.

- ⭐ **星标常用软件** 鼠标移到图标上，右上角出现星标；点一下把它加入「常用软件」，再点移出。常用软件沿用收藏夹里的应用收藏。

  **Star an app** Hover a tile and a star shows at its top-right; click to keep it in 常用软件 (the app favorites), click again to remove it.

- 🖱️ **和文件一样的右键菜单** 网格里的右键菜单与文件行相同：打开、以管理员身份运行、打开所在位置、复制、复制完整路径、复制名称、加入收藏夹等。

  **The same menu as files** Right-clicking a tile offers what a file's row does: open, run as administrator, open its location, copy, copy path, copy name, add to favorites.
