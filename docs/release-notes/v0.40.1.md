Win顺 0.40.1（自用构建）合并上游 0.40.0：剪贴板可以隐藏搜索框，备注可以带自己的颜色；设置窗口会记住上次的大小；应用内更新在窗口收起后会以管理员身份返回或询问；Everything 的完整路径匹配修复；缩略图加载更稳定。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.40.1 (a personal build) merges upstream 0.40.0: the clipboard's search box can be hidden, and notes can have a colour of their own; the Settings window remembers the size it was left at; in-app update comes back as administrator or asks once the windows are put away; the Everything full-path match is fixed; thumbnail loading is steadier. The personal 运行 tray icons, switch and scope memory stay.
