Win顺 0.37.1（自用构建）合并上游 0.37.0：插件库新增“开发工具”，搜索框打 `json` 就能格式化、压缩、转义剪贴板里的 JSON，`Enter` 打开树形窗口；截图识别的表格可以一格一格复制进 Excel；只装 WPS 的电脑也能预览 Word、Excel、PPT 里的文字；设置的分类更少、更好找；剪贴板也跟着“弹出动画”滑入淡出。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.37.1 (a personal build) merges upstream 0.37.0: Developer tools in the plugin library, where `json` formats, minifies or escapes the clipboard's JSON and Enter opens a tree view; a screenshot's words can be copied as a table; Word, Excel and PowerPoint preview as text without Office; settings are grouped in fewer, clearer categories; and the clipboard opens with the same animation as the search box. The personal 运行 tray icons, switch and scope memory stay.

## 新功能 · What's new

- ⬆️ **同步上游 0.37.0** 开发工具插件（`json` 加空格格式化、压缩、转义剪贴板 JSON，Enter 打开树形窗口，`.json` 文件右键“用 JSON 工具查看”）；截图文字“复制为表格”；没有 Office 时预览 Word、Excel、PPT 的文字；设置合成 12 类（常规、快捷键、外观、搜索范围、结果列表、系统整合、收藏夹、剪贴板、插件、AI 助手、运行状况、拾穗计划），Ctrl+F 可搜；剪贴板跟随“弹出动画”；带公式的文字按原样显示；剪贴板里单个文件的预览与搜索一致；对话框栏在规则窗口支持 Ctrl+Enter；目录链接在已索引磁盘也按自身路径列出。详见上游 0.37.0 的发布说明。

  **Upstream 0.37.0 merged** Developer tools (`json` formats, minifies or escapes the clipboard's JSON, Enter opens a tree view, and `.json` files have View in JSON tool); Copy as a table for a screenshot's words; Word, Excel and PowerPoint preview as text without Office; twelve clearer settings categories, searchable with Ctrl+F; the clipboard opens with the same animation; text with formulas shows as it looked; a single copied file's preview matches the search's; Ctrl+Enter in dialog-rule windows; directory links on indexed disks listed under their own paths too. See the upstream 0.37.0 notes.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.

- 🔌 **插件** 截图与录屏 1.1.25、图片文字搜索 1.0.23、资源管理器标签页 1.1.5、语义搜索 1.0.5、云备份 1.0.1（从插件库更新）。

  **Plugins** Screenshot and recording 1.1.25, image text search 1.0.23, Explorer tabs 1.1.5, semantic search 1.0.5 and cloud backup 1.0.1, from the plugin library.
