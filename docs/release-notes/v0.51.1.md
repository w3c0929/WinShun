## 新功能 · What's new

- 📋 **剪贴板打开就钉住** 设置里可以选打开时钉住，连着粘贴多条不用每次按 `Ctrl+T`。

  **The clipboard opens pinned** A setting keeps it pinned as it opens, so several entries paste without Ctrl+T each time.

- ⌨️ **终端开在文件夹里** 在文件夹里打 `cmd`、`wt` 等终端名，按 `Enter` 就开在这个文件夹里（#430）；面板会统计内容搜索的文件数（#476）。

  **A terminal in the folder** Typing cmd, wt or another terminal in a folder opens it there on Enter (#430); the panel counts the files of a content search (#476).

- 🔎 **预览与面板** 预览里搜的词垫上底色，第一处所在的行整行衬出（#482）；面板大图模式的底栏可以排序（#483）；清空搜索框后预览窗口随之关闭（#492）。

  **Preview and panel** A preview tints the words searched for and lights the whole row of the first hit (#482); the panel's large-picture mode sorts from its footer (#483); the preview closes when the box is emptied (#492).

- 🧩 **插件与更新** 翻译、按意思找、云备份的卡片上有“测试连接”（#495）；便携版的更新下载放进 `data\Updates`（#484）；服务返回的内容记进日志（#487）；插件筛选有清除按钮并显示数量。

  **Plugins and update** Test connection on the translation, search-by-meaning and cloud backup cards (#495); a portable copy keeps update downloads in data\Updates (#484); what the service answered goes into the journal (#487); the plugin filters have a clear button and a count.

- 🎨 **其他修复** 截图打码的隐藏线、`Shift+C` 的提示卡（#489）、公式窗口的图标、选中矩形在预览里的检查（#498）；演示黑板的黑；RGB32 图片的透明字节（#497）；文件夹菜单的开关与其行（#493）。

  **The rest** Capture's hidden-line style and Shift+C's note (#489), the formula window's icon, a selected rectangle checked in the preview (#498); the presenter's black board; an RGB32 picture's alpha byte (#497); the folder menu's switch and its rows (#493).

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
