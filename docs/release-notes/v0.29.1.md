Win顺 0.29.1（自用构建）合并上游 0.29.0：资源管理器右键可把图片贴到屏幕，自己的命令可进文件和文件夹的右键菜单，剪贴板图片行高三档、多张图片有缩略图，界面字体不再因中英文名失效；自用的「运行」托盘图标与「运行」标签继续保留，并新增一个默认开启的开关。 WinShun 0.29.1 (a personal build) merges upstream 0.29.0: pictures pin to the screen and your own commands enter files' right-click menus in Explorer, clipboard picture rows come in three sizes and several pictures get a thumbnail, and the interface font no longer fails under its English name; the personal 运行 tray icons and tags stay, now behind a switch that is on by default.

## 下载 · Downloads

## 新功能 · What's new

- ⬆️ **同步上游 0.29.0** 资源管理器里右键图片可「贴到屏幕（Win顺）」，多选各贴一张；设置 › 收藏夹里的命令可以勾选「显示在文件和文件夹的右键菜单里」，把完整路径交给 `{query}`；剪贴板「图片缩略图」分小/标准/大三档，一次复制多张图片显示第一张缩略图和数量；界面字体用中文名或英文名都能记住；浏览器书签插件 2.0.5 支持拼音。详见上游 0.29.0 的发布说明。

  **Upstream 0.29.0 merged** Explorer's picture menu offers "Pin to screen (WinShun)", each of several chosen pinned; a command in Settings › Favorites can appear in files' and folders' right-click menus, handing the full path to `{query}`; clipboard picture thumbnails come in Small, Standard and Large, and several copied pictures show the first with their number; an interface font is remembered under either its Chinese or English name; the Browser bookmarks plugin 2.0.5 reads pinyin. See the upstream 0.29.0 notes.

- 🎛️ **托盘程序开关（默认开）** 设置 › 结果列表 ›「运行里的托盘程序」控制自建的通知区域图标：关闭后「应用 › 运行」只列窗口，「全部」搜索不读取托盘，也不再每 3 秒巡检图标。默认开启，保持现在的体验。

  **A switch for the tray programs (on by default)** Settings › Results › "Tray programs in 运行" controls the personal notification-area rows: off, Apps › Running lists the windows alone, 全部 does not read the tray, and the icons are no longer walked every 3 s. On by default, as today.

- 🧩 **自用保留** 托盘行与「运行」标签、范围标签记忆（开启“每次打开时清空搜索”也记住）、双击记忆、运行页只在窗口/托盘变化时重排，均继续保留。

  **Kept from the self-build** The tray rows and 运行 tags, the scope tab remembered across openings (even with "clear on open"), the double-click memory, and 运行 laid out again only when the windows or icons changed.
