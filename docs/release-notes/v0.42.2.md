Win顺 0.42.2（自用构建）在 0.42.1 的基础上：中键固定的搜索窗现在是一个真正的常驻窗口——任务栏里有按钮，Alt+Tab 能切换到，可以最小化再还原，显示桌面后也能从任务栏找回；再按中键或 Ctrl+T 取消固定，恢复成原来不占任务栏的悬浮搜索框。 WinShun 0.42.2 (a personal build) builds on 0.42.1: the search window pinned with the middle button is a window of the desktop now — a taskbar button, Alt+Tab, minimize and restore, found again from the taskbar after Show desktop; unpinned (the middle button or Ctrl+T again), it is the floating box it was, with no trace in the taskbar.

## 新功能 · What's new

- 📌 **固定的搜索窗常驻桌面** 中键（或 `Ctrl+T`）固定搜索框后，它不再只是一个钉住的浮窗：任务栏出现 Win顺 的按钮，`Alt+Tab` 里能选到它，可以最小化、从任务栏还原，按 `Win+D` 显示桌面后也能找回来；按热键唤起时若它已最小化，会先还原再出现。再按中键或 `Ctrl+T` 取消固定，恢复为原来的悬浮搜索框，任务栏和 `Alt+Tab` 里都不留痕迹。样式切换在原生窗口上完成，不重建窗口，外观和原来的钉住行为不变。

  **The pinned box stays as a window of the desktop** Pinned with the middle button (or `Ctrl+T`), the search window gets a taskbar button, an `Alt+Tab` entry, minimize and restore (the hotkey restores it first when minimized), and is found from the taskbar after Show desktop. Unpinned, it is the floating box it was, out of the taskbar and `Alt+Tab` again. The native styles are switched on the same window, without recreating it, so it looks and behaves as pinned did.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.
