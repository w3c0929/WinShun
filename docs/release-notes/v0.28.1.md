Win顺 0.28.1（自用构建）合并上游 0.28.0：软件可以按 Windows 里的安装名称搜到，网页搜索可在没找到时兜底，文件夹内打字、截图、剪贴板和安装都有更新；自用的「应用 › 运行」托盘图标与「运行」标签继续保留。 WinShun 0.28.1 (a personal build) merges upstream 0.28.0: software is found by the name Windows lists it under, web search answers when nothing was found, and typing in folders, capture, clipboard and setup all moved on; the personal 运行 tray icons and 运行 tags stay.

## 新功能 · What's new

- ⬆️ **同步上游 0.28.0** 软件现在也按 Windows「应用」里的安装名称查找（例如 visio、Microsoft Office），套件名不会把旁边的程序一起带出来；「全部」没找到时可以按设置用网页搜索兜底；搜索面板空着时可选择列出全部文件；文件夹窗口里打字不再被按住的鼠标或输入法打断组合；截图可识别二维码并进入搜索与历史，PrtScn 被系统占用后会重试，图钉支持 O/U/E 快捷键；剪贴板隐藏条目的省略号和文本文件预览；安装包的 SendTo 局域网传输与卸载清理；随包携带并校验完整 C++ 运行时；插件更新到 1.1.14，书签支持拼音。详见上游 0.28.0 的发布说明。

  **Upstream 0.28.0 merged** Software is also found by the name Windows lists it under (visio, Microsoft Office), without a suite's name bringing its neighbours along; 全部 can fall back to a web search; the panel can list nothing until asked; typing in a folder's window is no longer cut by a held mouse button or an input method's composition; captures read QR codes, PrtScn is retried when Windows takes it back, pins take O/U/E; clipboard entries kept from view show dots and text files preview their words; the setup adds SendTo LAN transfer and cleans it on uninstall; the whole C++ runtime ships and is checked; plugins 1.1.14 and pinyin for bookmarks. See the upstream 0.28.0 notes.

- 🧩 **自用保留：托盘运行** 「应用 › 运行」继续列出通知区域里没有窗口的图标，「全部」搜索也能找到它们并显示「运行」标签；有窗口的程序仍优先切窗口，只在托盘的按其图标打开，需要双击的会记住。

  **Kept: the tray in 运行** Apps › Running keeps the notification-area icons that have no window, and 全部 finds them with a 运行 tag. A program with a window is switched to; a tray-only one is clicked through its icon, and one that wants a double click remembers it.

- ⌨️ **运行页不再打断方向键** 窗口和托盘没有变化时不再重排，选中项不会每 1.5 秒跳回第一格；只有真的开了、关了、改了标题或图标来去时才重建。

  **The 运行 grid leaves the arrow keys alone** It is laid out again only when a window or a tray icon actually came, went, or was renamed, not on every 1.5 s tick.

- 🐞 **修复运行页偶尔一直为空** 从「全部」切回「运行」时，如果窗口和托盘没有变化，页面可能继续显示上一个范围的列表；现在会确认网格里就是运行列表，否则一定重建。

  **The 运行 page no longer stays empty** Coming back from a 全部 search with the same windows and icons could leave the other list (or nothing) on screen; the grid is now rebuilt unless it is known to show the 运行 list.
