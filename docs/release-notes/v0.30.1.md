Win顺 0.30.1（自用构建）合并上游 0.30.0：截图可以翻译并把译文排回原位置，识别文字窗口也能翻译；剪贴板文字能直接修改，书签插件能搜浏览器历史；另有字母直达、搜索框直接打开网址和几处输入修正；自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.30.1 (a personal build) merges upstream 0.30.0: captures translate in place and the text-recognition window translates too; clipboard text can be edited, and the bookmarks plugin searches browser history; letter jump, addresses typed into the search box and several input fixes arrive as well; the personal 运行 tray icons, switch and scope memory stay.

## 下载 · Downloads

- **WinShun-0.30.1-x64-setup.exe** 标准安装版，覆盖升级保留设置、索引和剪贴板。
- **WinShun-0.30.1-x64-portable.zip** 便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.30.1-x64-offline-setup.exe** 含增强 OCR 的完整离线安装包。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 增强 OCR 组件。
- **SHA256SUMS.txt** 上述文件的 SHA256。

## 新功能 · What's new

- ⬆️ **同步上游 0.30.0** 截图工具条新增「翻译」，译文排回原位置，可 Tab 切换原文/译文；识别文字窗口也能翻译，并可先改文字或选中一部分；剪贴板文本记录可「修改文字…」；书签插件 2.1.0 用 `bh`/`ls` 搜 Chrome、Edge 历史；打码工具点一下遮住整行文字；「字母直达」用字母打开结果；搜索框里可直接打开网址，也可填入刚复制的单行文字；面板快捷键再按一次关闭，此电脑/主文件夹里打字也搜整台电脑；插件在搜索框里改的设置会同步到设置页。详见上游 0.30.0 的发布说明。

  **Upstream 0.30.0 merged** The capture toolbar translates in place (Tab switches original and translation); the text-recognition window translates too, with edits or a selection first; a clipboard text entry can be edited; Browser bookmarks 2.1.0 searches Chrome and Edge history with `bh`/`ls`; the redact tool hides a line at a click; Letter jump opens a row with a letter; the search box opens a typed address and fills in one just copied; the panel's hotkey closes it again, and typing on This PC searches the whole PC; a plugin's setting changed in the search box reaches the settings page. See the upstream 0.30.0 notes.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。构建脚本改用上游的 VC 运行时发现，自建线与上游少一处分叉。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay. The build script now uses upstream's VC runtime discovery, removing one divergence.
