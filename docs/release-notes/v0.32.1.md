Win顺 0.32.1（自用构建）合并上游 0.32.0：搜索结果可以按住右键拖到资源管理器再选复制或移动，对话框旁的搜索框回车打开、`Ctrl+Enter` 转到；文件夹菜单不再自己一层层钻进去，换页不再跳到鼠标下面，收藏夹可以直接显示；指向其他磁盘的目录链接会自动收进索引；插件库能看每一版的更新内容；截图翻译可以用其他翻译插件；关键字命令能边打边列出文件。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.32.1 (a personal build) merges upstream 0.32.0: drag results into File Explorer with the right button and choose copy or move; the bar by file dialogs opens with Enter and goes there with Ctrl+Enter; the folder menu no longer walks down by itself, pages keep their place, and favorites can be shown directly; directory links to other disks are indexed by themselves; the plugin library shows what each version changed; screenshot translation works through any translator plugin; keyword commands list files as you type. The personal 运行 tray icons, switch and scope memory stay.

## 新功能 · What's new

- ⬆️ **同步上游 0.32.0** 右键拖出结果；对话框搜索框回车打开、`Ctrl+Enter` 转到；目录链接自动索引；插件库“更新内容”；截图翻译支持其他翻译插件；关键字命令边打边列文件。文件夹菜单不再自己下钻、换页保持位置，收藏夹可直接显示（设置 › 打开 Win顺 › 对话框 › 文件夹菜单，0–10 个）；选文件夹的乱码路径自动修正；F2 改名的输入框不再盖住原名；应用 › 运行里也有 Win顺 自己的窗口。详见上游 0.32.0 的发布说明。

  **Upstream 0.32.0 merged** Drag results out with the right button; Enter opens and Ctrl+Enter goes there in the bar by file dialogs; directory links are indexed by themselves; What's new in the plugin library; screenshot translation through any translator plugin; keyword commands list files as you type. The folder menu no longer walks down by itself, pages keep their place, and favorites can be shown directly (Settings › Open WinShun › Dialogs › Folder menu, 0–10); garbled paths from folder pickers are put right; the F2 box no longer covers the old name; Apps › Running lists WinShun's own windows too. See the upstream 0.32.0 notes.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.

- 🔌 **插件** 截图与录屏 1.1.18、图片文字搜索 1.0.17、资源管理器标签页 1.1.3、翻译 2.2.3、快捷跳转 1.2.0（从插件库更新）。

  **Plugins** Screenshot and recording 1.1.18, image text search 1.0.17, Explorer tabs 1.1.3, Translate 2.2.3 and Go to 1.2.0, from the plugin library.
