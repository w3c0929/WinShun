Win顺 0.26.2（自用构建）基于上游最新主干（0.25.0 + 已合并的「应用」标签），用 Qt 6.12 构建。应用标签默认关闭，在 设置 › 结果列表 › 应用 打开后出现在标签栏最后。 WinShun 0.26.2 (a personal build) is upstream's latest main (0.25.0 plus the merged 应用 tab), built with Qt 6.12. The Apps tab is off by default; turn it on under Settings › Results. It then sits last among the tabs.

## 下载 · Downloads

## 新功能 · What's new

- 🧩 **应用标签（GitHub #296）** 上游合并后的实现：标签栏最后的「应用」用图标网格列出程序，类型条分为 常用 / 收藏 / 全部（各带数量），可用 Ctrl+Tab 切换；星标把程序加入收藏；右键弹出与文件行相同的菜单；方向键选择、Enter 打开、输入按名字过滤。默认关闭，需在 设置 › 结果列表 打开。

  **The Apps tab (GitHub #296), as upstream merged it** A grid of app icons as the last tab: the strip chooses 常用, 收藏 or 全部 (with counts); the star keeps one in the favorites; right-click offers the same menu a file's row has. Off by default; turn it on under Settings › Results.

- 🖧 **其他上游改动** 0.25.0 的局域网传输 1.0.7（默认关闭自动接收）、设置窗口最大化时保留背景、安装/升级在文件被占用时继续、应用内更新链路等。

  **Other upstream changes** LAN transfer 1.0.7 (auto-accept off), the settings window keeps its backdrop when maximized, setup continues when a file is held by another program, and the in-app update path.
