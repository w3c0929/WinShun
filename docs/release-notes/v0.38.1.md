Win顺 0.38.1（自用构建）合并上游 0.38.0：文件夹菜单的列宽跟着名字收紧，文件夹的列里也能列出里面的文件；剪贴板里的文字按 `F3` 可以贴到屏幕上，预览里拖选一段可以只复制或粘贴这部分，打开位置新增“上次的位置”；搜索框打“设置”直达 Win顺 或插件的设置；“在终端中打开”可以选 PowerShell、Windows 终端、Git Bash 等；空文件夹和空文件一眼看得出。自用的「运行」托盘图标、开关与范围记忆继续保留。 WinShun 0.38.1 (a personal build) merges upstream 0.38.0: folder menu columns are as wide as their names and a folder's column lists its files too; text on the clipboard pins to the screen with F3, part of an entry can be copied or pasted from the preview, and the clipboard can open where it was last left; “settings” in the search box opens WinShun's or a plugin's settings; Open in terminal can use PowerShell, Windows Terminal, Git Bash and more; empty folders and files are marked. The personal 运行 tray icons, switch and scope memory stay.

## 新功能 · What's new

- ⬆️ **同步上游 0.38.0** 文件夹菜单列宽按名字收紧、文件夹列可列出文件（#384），滚轮按系统行数滚动；剪贴板文字 `F3` 贴到屏幕（需截图与录屏 1.1.26）、预览拖选只复制/粘贴选段、打开位置“上次的位置”、菜单快捷键不开菜单也能按；搜索框打“设置”直达 Win顺/插件设置并可收藏；在终端中打开可选终端（#386）；空文件夹和空文件带标记（#391）；快捷筛选可带自己的排序（#392）；对话框栏在 Windows 10 不再黑闪。详见上游 0.38.0 的发布说明。

  **Upstream 0.38.0 merged** Folder menu columns fit their names and list a folder's files too (#384), the wheel follows the system's lines; clipboard text pins to the screen with F3 (needs Screenshot and recording 1.1.26), a part of an entry can be copied or pasted from the preview, Where it was last opens the clipboard where you left it, and the menu's keys work with the menu closed; “settings” in the search box opens WinShun's or a plugin's settings, as favorites; Open in terminal picks the terminal (#386); empty folders and files are marked (#391); quick filters can have their own sort (#392); no black flash in the dialog bar on Windows 10. See the upstream 0.38.0 notes.

- 🧩 **自用保留** 运行页的托盘图标、全部搜索里的托盘程序与「运行」标签、托盘开关（默认开）、范围标签记忆、双击记忆，均继续保留。

  **Kept from the self-build** The tray rows in 运行, the tray programs and 运行 tags in 全部, the tray switch (on by default), the scope tab remembered across openings, and the double-click memory stay.

- 🔌 **插件** 截图与录屏 1.1.26（文字贴到屏幕需要它），从插件库更新。

  **Plugins** Screenshot and recording 1.1.26, needed for pinning text to the screen, from the plugin library.
